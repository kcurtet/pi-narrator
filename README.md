# pi-narrator

Extensión de [pi](https://github.com/earendil-works/pi) que narra en voz alta qué hizo el agente tras cada turno, en el idioma en que escribe el usuario.

Voz: piper (TTS neural offline) → speech-dispatcher → espeak-ng.

Estado: desarrollo (spec: `docs/specs/001-narrator/`).

Instalación y uso: se documentará al finalizar v1.
